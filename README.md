# Домашние задания по машинному обучению — 2026

## ДЗ №1. Первичный анализ данных

Решение: [1_homework/1_homework_eda.ipynb](1_homework/1_homework_eda.ipynb).

В блокноте выполнены шесть заданий; сохранены выводы ячеек и итоговые графики.
Исходные данные находятся в папке `1_homework/data`.

### Запуск

```bash
python -m pip install -r requirements.txt
cd 1_homework
jupyter notebook 1_homework_eda.ipynb
```

В Jupyter выполните перезапуск ядра и запуск всех ячеек по порядку.

Исходное задание и данные: https://github.com/IImbryk/ml_2026/tree/main/1_homework

## ДЗ №2. Исследовательский анализ данных

Решение: [2_homework/2_homework_eda_feature_engineering.ipynb](2_homework/2_homework_eda_feature_engineering.ipynb).

Выполнены семь заданий: временной диапазон, описательная статистика, статистика по сезонам,
уровни загрузки, PCA, кластеризация KMeans и спектральный анализ. В блокноте сохранены
результаты самопроверок и график спектра. Данные находятся в `2_homework/data`.

Запуск после установки зависимостей из `requirements.txt`:

```bash
cd 2_homework
jupyter notebook 2_homework_eda_feature_engineering.ipynb
```

Исходное задание и данные: https://github.com/IImbryk/ml_2026/tree/main/2_homework
